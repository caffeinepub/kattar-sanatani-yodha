# Specification

## Summary
**Goal:** Replace the "Vedic Study Circles" program card text with Hindi translations on the Programs page.

**Planned changes:**
- Change the program card title from "Vedic Study Circles" to "वैदिक स्टडी सर्कल"
- Replace the program card description with Hindi text: "वेद, उपनिषद और भगवद गीता जैसे पवित्र ग्रंथों की पढ़ाई और चर्चा के लिए रेगुलर सेशन। अनुभवी विद्वानों से सीखें और अपनी आध्यात्मिक समझ को गहरा करें।"

**User-visible outcome:** Users will see the Vedic Study Circles program card displayed in Hindi on the Programs page, while other program cards remain in English.
