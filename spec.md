# Specification

## Summary
**Goal:** Translate the entire user-facing UI of the Kattar Sanatani Yodha app from English to Hindi.

**Planned changes:**
- Translate all text in the Navigation component (nav links, mobile menu labels, admin link) to Hindi
- Translate all text in the Hero component (tagline, mission statement, CTA buttons, scroll indicator) to Hindi
- Translate all text in the Mission component (section heading, paragraph, all four core value card titles and descriptions) to Hindi
- Translate all text in the SupportOptions component (headings, option titles, descriptions, CTA labels) to Hindi
- Translate all text on the Home page (section headings, highlight cards, CTA section) to Hindi
- Translate all text on the About page (hero section, story text, principle cards) to Hindi
- Translate all text on the Programs page (headings, program cards, impact statistics labels) to Hindi
- Translate all text on the Philosophy page (headings, principle titles, body text, devotion examples) to Hindi
- Translate all text on the Resources page (hero, category headings, item titles, labels) to Hindi
- Translate all text on the Contact page (form labels, placeholders, submit button, contact info labels, success/error messages) to Hindi
- Translate all text on the Donate page (headings, support descriptions, impact labels, transparency text) to Hindi
- Translate all text on the Admin page (dashboard headings, table headers, search/filter labels, action buttons, error messages) to Hindi
- Translate all text in the Footer component (section headings, link labels, attribution text) to Hindi

**User-visible outcome:** Every visible text string across all pages and shared components is displayed in Hindi, while the existing theme, layout, Sanskrit terms, and organization name remain unchanged.
