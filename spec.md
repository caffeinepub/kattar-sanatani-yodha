# Specification

## Summary
**Goal:** Translate the entire user-facing UI of the Kattar Sanatani Yodha app from English to Hindi, covering all pages and shared components.

**Planned changes:**
- Translate all text in the Navigation component (nav links, mobile menu, admin link) to Hindi
- Translate all text in the Hero component (tagline, mission statement, buttons, scroll indicator) to Hindi
- Translate all text in the Mission component (heading, paragraph, four core value cards) to Hindi
- Translate all text in the SupportOptions component (heading, four card titles, descriptions, CTA links) to Hindi
- Translate all text on the Home page (highlights grid, activity cards, CTA section) to Hindi
- Translate all text on the About page (hero section, story text, four principle cards) to Hindi
- Translate all text on the Programs page (headings, six program cards, impact statistics labels) to Hindi
- Translate all text on the Philosophy page (headings, principle titles, body text, devotion examples) to Hindi
- Translate all text on the Resources page (hero section, four resource category cards, item titles, buttons/links) to Hindi
- Translate all text on the Contact page (form labels, placeholders, submit button, contact info, social media labels) to Hindi
- Translate all text on the Donate page (headings, support options, impact area labels, transparency text) to Hindi
- Translate all text on the Admin page (dashboard headings, search placeholder, filters, table headers, action buttons, error messages) to Hindi
- Translate all text in the Footer component (quick links, contact/social headings, attribution/copyright) to Hindi
- Preserve any text already written in Hindi or Sanskrit

**User-visible outcome:** Every visible text string across all pages and shared components is displayed in Hindi instead of English, with no layout or styling changes.
